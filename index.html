Oshare批發 App 隱私權政策

本政策適用於 Oshare批發 App 及與其連線之後台服務。
（建議可自行補上「最後更新日」）

本 App 為批發／經銷業務使用之出貨與追溯工具。我們重視您的隱私，以下說明本 App 如何收集、使用與保護您的資料。

一、收集的資料類型與用途

1. 帳號登入資料

您登入時使用的電子郵件與密碼（由我們為您建立帳號），用於身分驗證與權限管理。登入資訊由 Google Firebase Authentication 處理；密碼經加密儲存。

2. 使用者資料（姓名、角色）

您的顯示名稱、帳號角色（如 Admin／經銷商／合作商／批發商），儲存於後台，用於出貨登記與流向紀錄中顯示經手人／當前持有者。

3. 業務操作紀錄

產品條碼／QR Code 掃描結果、出貨對象、入庫／出貨時間、操作者等流向紀錄，用於出貨登記、資料查詢與商品追溯。資料儲存於 Google Firebase Firestore。

4. 相機

本 App 使用裝置相機掃描產品條碼或 QR Code，僅用於即時辨識條碼內容，不會拍攝或儲存照片。若不同意相機權限，將無法使用掃描相關功能。

二、資料分享與第三方服務

本 App 使用 Google Firebase（Authentication、Firestore）處理登入與資料儲存。我們不會將您的個人資料出售給第三方，亦不會用於未載明之行銷或廣告目的。

三、資料保留與安全

業務操作紀錄會依營運需求保留於後台。我們透過 Firebase 之安全機制保護資料傳輸與儲存；請您妥善保管登入帳號與密碼。

四、您的權利

您可透過我們提供之管道請求查詢、更正個人資料。若不再使用本 App，可聯繫我們要求停止使用或刪除帳號及相關資料。

五、政策變更

我們可能因法規或服務調整而更新本政策，更新後將於 App 或適當管道通知；繼續使用即視為同意更新後之內容。

六、聯絡我們

若對本隱私權政策或資料處理有任何疑問，請透過您與我們之業務聯絡管道與我們聯繫。
